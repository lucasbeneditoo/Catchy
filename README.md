# Catchy

**A desktop music player for your local music library.**

Catchy is an open-source music player built with C#, Avalonia UI and LibVLCSharp. Its goal is to provide a flexible way to organize, manage and listen to local music collections.

## Features

- Local music playback
- Audio library scanning
- Playback queue management
- Play, pause, next and previous controls
- Seekbar and volume control
- Shuffle and repeat modes
- Audio metadata and album artwork

## Built With

- C#
- .NET
- Avalonia UI
- LibVLCSharp
- SQLite (planned)

## Project Status

Catchy is currently under development. New features and improvements are being implemented.
